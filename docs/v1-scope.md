# v1 Scope

## v1 の目的
v1 は、匿名MVPとして公開し、無料ファネルと初回課金導線の有効性を検証するためのバージョンです。

## v1 で必ずやること
- LP
- 診断12問
- 結果表示
- つまずきポイント表示
- 無料1問模擬面接
- フィードバック表示
- Offer表示
- Checkout導線
- Success確認中画面
- 法務ページ
- 問い合わせページ
- エラーハンドリング
- 計測イベント

## v1 でやらないこと
- ログイン
- マイページ
- 継続課金
- 外部求人連携
- 音声入力本実装
- 音声読み上げ本実装
- リアルタイム面接会話
- 管理画面
- 高度な推薦アルゴリズム

## v1 の匿名利用方針
- 無料は匿名利用
- sessionStorage による一時保持
- リロード復元対応
- 購入時のみメール取得前提

## 成功判定
最低限、以下が見えること。
- LP CTA率
- 診断完了率
- 模擬面接開始率
- フィードバック閲覧率
- Offer到達率
- paid_cta_click率
- checkout_start率
- purchase_confirmed率

## v1 で最重要なこと
- 面接不安に刺さること
- 無料体験だけで価値が伝わること
- ただし無料で完結しすぎないこと
- 有料導線が自然であること
