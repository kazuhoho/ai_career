# Marketing Notes

## このプロダクトの売り方
売るのは「診断結果」ではなく、以下です。

- 面接で詰まらないための練習
- 自己PR・志望動機の改善
- 面接本番前の不安軽減

## 刺さるペイン
- 面接で何を話せばいいかわからない
- 自己PRが弱い
- 転職理由がうまく整理できない
- 本番で頭が真っ白になりそう
- 今の会社を辞めるべきか迷っている

## LPで伝えるべきこと
- あなたは面接でどこで詰まりやすいのか
- その弱点は無料で可視化できる
- 実際に1問答えることで、自分の課題を体感できる
- 有料では、改善の練習と具体策が得られる

## Offerの考え方
商品を均等に並べるのではなく、
「今のあなたにはこれが最優先」と理由付きで提案する。

## 勝ち筋
診断 → つまずき可視化 → 1問体験 → フィードバック → Offer

## SNSの切り口
- 面接で落ちやすい人の共通点
- 自己PRが弱く見える言い方
- 転職理由で一気に不利になる表現
- 30秒で答えられない人の特徴
- 面接官が「浅い」と感じる回答
- 強みが伝わらない人の話し方

## 改修の優先順位
1. LPの見出し
2. 結果ページの刺さり方
3. 模擬面接後のフィードバック説得力
4. Offerの最優先商品表示
5. CTA文言

## マーケ改善時の注意
- 診断サイトっぽくしすぎない
- 性格診断で終わらせない
- 面接の痛みから離れない
- 無料が良すぎて完結しないようにする
