# ClaudeCode / Codex 実装指示

このリポジトリは、面接不安を持つ匿名ユーザー向けの AI面接リハーサルMVP です。

## 目的
LP → 診断 → 結果 → 模擬面接 → フィードバック → Offer までの無料ファネルを完成させ、Offer → Checkout → Success の課金導線を成立させること。

## v1 前提
- ログインなし
- 無料利用は匿名
- sessionStorage ベース
- mypage は v1 対象外
- success は Webhook 確認前提
- 購入時のみメール取得前提
- 音声本実装なし
- 求人APIなし

## 実装時の原則
1. まずコードを読んで現状把握する
2. 既存の責務分離を壊さない
3. mock / production の境界を壊さない
4. UX / マーケ改善前提で、導線の強さを落とさない
5. v1 スコープ外の機能を勝手に膨らませない

## 最優先タスク
1. 無料ファネルを URL ベースで安定化
2. Offer の推奨順ロジック実装
3. Checkout / Success / Webhook 構造追加
4. 法務ページと contact 追加
5. error / loading / not-found を追加
6. typecheck / lint / build が通るようにする

## 次にやること
まず、現在のリポジトリを読んで以下を出してください。
- 現状把握
- ギャップ一覧
- 実装順序
- 変更ファイル一覧

その後、最優先タスクから順に実装してください。

## 実装完了時に見せてほしいもの
- ディレクトリ構成
- 無料ファネルの画面キャプチャ
- Offer の推奨ロジックと文言
- Checkout / Success の挙動
- README の v1 制約記述
- 未実装一覧

## 短い実行指示

上記ドキュメント一式を前提に、まず以下を実施してください。

1. README / docs / issue template / env / ci をリポジトリへ反映
2. v1 スコープ外機能が混ざっていないか確認
3. 無料ファネルの導線をコードベースで再点検
4. Offer / Checkout / Success / Contact の不足を洗い出す
5. 実装順序を issue 化する

まずは、反映後のファイル一覧と、最初に着手する issue 順を提示してください。
